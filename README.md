### &#128444; Практический проект «ИРВАС» (Остекление балконов)

🎓 Учебный проект Приложение разработано в рамках прохождения курса по JavaScript (Udemy). Цель проекта — детальное изучение модульной архитектуры на чистом JS (ES6+), работы с асинхронными запросами (Fetch/AJAX), паттернов проектирования UI-компонентов и инструментов сборки фронтенда.

Интерактивное веб-приложение для расчета и заказа остекления балконов с динамическим многошаговым интерфейсом, автоматической валидацией данных и интеграцией с бэкенд-скриптами для отправки заявок.

---

### 🌟 Реализованный функционал

В ходе работы над проектом были созданы и связаны между собой следующие интерактивные модули: 

* **Динамические табы:** Позволяют пользователю переключаться между различными профилями окон, типами остекления и примерами отделки без перезагрузки страницы.
* **Кастомные модальные окна:** Окна «Вызов замерщика» и «Заказать звонок» с продвинутой логикой закрытия (по клику на крестик, на серую область вокруг или по нажатию клавиши Escape), а также автоматическим появлением на экране по таймеру.
* **Многошаговый калькулятор:** Интерактивный интерфейс выбора формы балкона, типа профиля и остекления с аккумулированием всех параметров в единый глобальный объект состояния.
* **Асинхронная отправка форм:** Сбор данных (включая параметры из калькулятора) и отправка на сервер через FormData/AJAX с визуальным информированием пользователя о статусах (загрузка, успех, ошибка).
* **Валидация полей ввода:** Встроенная защита текстовых полей номеров телефонов от случайного ввода букв и спецсимволов с использованием регулярных выражений.
* **Таймер обратного отсчёта:** Информационный блок с динамическим обратным отсчетом времени до завершения маркетинговой акции.
* **Просмотр изображений (Lightbox):** Кастомная галерея для увеличения фотографий выполненных работ во весь экран по клику, реализованная без использования сторонних тяжелых библиотек.

### 🛠 Технологический стек и навыки

* **JavaScript (ES6+):** Модульная структура кода, инкапсуляция логики, управление состоянием приложения (state), работа с DOM-деревом и делегированием событий.
* **Асинхронность & API:** Отправка форм через AJAX, обработка FormData, взаимодействие с бэкенд-скриптами, обработка ответов сервера.
* **Сборка проекта:** Gulp (конфигурация тасков, компиляция разрозненных JS-файлов в единый бандл, минификация ресурсов, интеграция локального сервера BrowserSync).
* **Инструменты и фичи:** Работа со временем (Date) для таймеров обратного отсчета, валидация полей через регулярные выражения (RegExp), построение архитектуры многошаговых интерфейсов.
* **Серверная часть:** Обработка входящих данных на стороне сервера при помощи скриптов PHP (server.php).

### 🚀 Как запустить проект локально

1. Установите [Node.js](https://nodejs.org/).
2. Склонируйте репозиторий и перейдите в папку: 

bash

git clone https://github.com/DragonVlad/Irvas-Balconies-Gulp.git
cd Irvas-Balconies-Gulp

3. Установите все необходимые зависимости проекта: 

bash

npm install

4. Запустите сборщик Gulp для открытия сайта локально: 

bash

npx gulp

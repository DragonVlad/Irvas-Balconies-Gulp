### 🪟 Практический проект «ИРВАС» (Остекление балконов)

🎓 **Учебный проект для портфолио**
Данный проект выполнен в ходе обучения на курсе **«Практический JavaScript» (автор: Иван Петриченко) на платформе Udemy**. 

Главная цель работы — закрепление теоретической базы JavaScript на практике, изучение модульной архитектуры и освоение инструментов автоматизации фронтенда под руководством ментора. 

### 📚 Чему я научился и что закрепил в этом проекте:

В процессе пошаговой реализации макета под руководством автора курса я освоил следующие навыки и концепции: 

1. **Разделение логики на ES6-модули:** Научился разбивать JavaScript-код на отдельные изолированные файлы (модули) для каждой контентной зоны (модальные окна, табы, формы) с последующим экспортом и импортом в единую точку входа.
2. **Работа со сложным состоянием (State):** Понял, как аккумулировать данные из разных шагов интерфейса (выбор формы балкона -> выбор профиля -> выбор остекления) в один общий объект для последующей отправки.
3. **Асинхронные запросы (AJAX & FormData):** Закрепил на практике отправку данных с форм на сервер без перезагрузки страницы, обработку состояний «загрузка», «успех» и «ошибка».
4. **Управление DOM-деревом и событиями:** Отработал делегирование событий, работу с кастомными дата-атрибутами (data-target), логику открытия/закрытия поп-апов и переключения табов.
5. **Создание кастомных UI-элементов:** Написал логику для галереи изображений (Lightbox) и динамического таймера акций на чистом JavaScript без использования сторонних плагинов.
6. **Автоматизация сборки через Gulp:** Освоил базовую работу со сборщиком пакетов — запуск локального сервера (BrowserSync), компиляцию ресурсов и запуск задач отслеживания изменений (watchers).

### 🛠 Технологический стек проекта

* **База:** HTML5, CSS3 (адаптивная верстка по готовому макету).
* **Скрипты:** Vanilla JavaScript (модульная структура ES6).
* **Сборка и автоматизация:** Node.js, NPM, Gulp (конфигурация предоставлена в рамках курса).
* **Контроль версий:** Git, удаленный репозиторий на GitHub.

### 🚀 Как запустить проект локально

1. Установите [Node.js](https://nodejs.org/).
2. Склонируйте репозиторий и перейдите в папку: 

bash

git clone https://github.com/DragonVlad/Irvas-Balconies-Gulp.git
cd Irvas-Balconies-Gulp

3. Установите все необходимые зависимости проекта: 

bash

npm install

4. Запустите сборщик Gulp для открытия сайта локально: 

bash

npx gulp
